# Time & Date Modules

The **Time & Date** tab generates real-time formatted clock and calendar text files (`Time.txt` and `Date.txt`) inside `shared/dynamic_text/` (or your custom output directory) for OBS Text sources.

---

## Time Module (`Time.txt`)

### Available Format Codes

| Code | Output | Example |
| :--- | :--- | :--- |
| `$h` | Hours (24h or 12h with AM/PM enabled) | `14` or `02` |
| `$m` | Minutes | `45` |
| `$s` | Seconds | `08` |
| `$tt` | AM / PM indicator (requires 12-hour option) | `PM` |

### Format Examples

| Format String | Resulting Output |
| :--- | :--- |
| `$h:$m:$s` | `16:15:35` |
| `$h:$m` | `16:15` |
| `$h:$m:$s $tt` | `04:15:35 PM` |
| `$h hours, $m mins` | `16 hours, 15 mins` |

---

## Date Module (`Date.txt`)

The **Date** module formats the current local date using localized day and month names matching your selected UI language (`fr` or `en`).

### Date Presets (`$date`)

| Preset | Output (English) | Output (French) |
| :--- | :--- | :--- |
| `$dd-MM-yy` | `11-11-26` | `11-11-26` |
| `$dd-MM-yyyy` | `11-11-2026` | `11-11-2026` |
| `$dd MMMM yyyy` | `11 November 2026` | `11 novembre 2026` |
| `$dddd dd MMMM yyyy` | `Wednesday 11 November 2026` | `mercredi 11 novembre 2026` |

### Output Template Examples

| Template | Resulting Output |
| :--- | :--- |
| `$date` | `Wednesday 11 November 2026` |
| `Today: $date` | `Today: Wednesday 11 November 2026` |
