# Installation & Compilation

Learn how to configure your build environment, install required system packages, and compile OSMV v5.1.0 from source.

---

## System Dependencies

Third-party header/UI libraries (`Dear ImGui`, `nlohmann/json`, `stb_image`, and embedded fonts) are already included in `third_party/` and `src/common/`. You only need a C++20 toolchain and OS libraries.

<Steps>

### Linux (Arch Linux, Ubuntu, Fedora)

OSMV requires **CMake (3.20+)**, **Ninja**, a **C++20 compiler** (`g++` or `clang++`), **libdbus-1** (for MPRIS & tray icon), **libcurl** (for HTTP/Twitch/Dynamic Files), **GLFW 3**, and **OpenGL**.

#### Arch Linux:
```bash
sudo pacman -S cmake ninja gcc pkgconf dbus curl glfw libgl
```

#### Ubuntu / Debian:
```bash
sudo apt update
sudo apt install cmake ninja-build g++ pkg-config libdbus-1-dev libcurl4-openssl-dev libglfw3-dev libgl-dev
# On Ubuntu 24.04 / Debian 12 (where libglfw3-dev is 3.3), also install Wayland dev headers so CMake builds GLFW 3.4 for native Wayland app_id:
# sudo apt install libwayland-dev libwayland-bin libxkbcommon-dev
```

#### Fedora:
```bash
sudo dnf install cmake ninja-build gcc-c++ pkgconf-pkg-config dbus-devel libcurl-devel glfw-devel mesa-libGL-devel
```

### macOS (Apple Silicon & Intel)

1. Install the **Xcode Command Line Tools**:
   ```bash
   xcode-select --install
   ```
2. Install **CMake**, **Ninja**, and **GLFW 3** using Homebrew:
   ```bash
   brew install cmake ninja glfw
   ```

### Windows

1. Install **Visual Studio 2022/2026 Build Tools** (select the **Desktop development with C++** workload and the **Windows 10/11 SDK** for C++/WinRT headers).
2. Install **CMake 3.20+** and **Ninja** (available in `PATH`).

</Steps>

---

## Building from Source

Once dependencies are installed, run the platform build script (which configures CMake in `Release`, compiles, runs the `osmv_unit_tests` CTest suite, and copies the binaries to the project root):

### On Linux:
```bash
chmod +x linux/build.sh
./linux/build.sh
```
This outputs `./osmv` (daemon) and `./osmv-gui` (GUI) at the project root.

### On macOS:
```bash
cmake -B macos/build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="/opt/homebrew;/usr/local"
cmake --build macos/build -j
ctest --test-dir macos/build --output-on-failure
```
This compiles `./macos/build/osmv` (daemon with native menu bar icon) and `./macos/build/osmv-gui` (Dear ImGui interface with OpenGL 3 Core).

If running pre-built release binaries downloaded from GitHub, clear the quarantine attribute if prompted by Gatekeeper:
```bash
xattr -cr .
./osmv-gui
```

### On Windows:
```cmd
windows\build.bat
```
This outputs a single standalone `OSMV.exe` (~1.94 MB, no external DLLs required) at the project root.
