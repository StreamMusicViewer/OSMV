# FAQ

Frequently Asked Questions and troubleshooting tips for OSMV v5.0.0.

---

## How do I bring back the configuration window?

Closing the window `[X]` or clicking **Minimize to Tray** / **Mode Headless** terminates the GUI process so it consumes 0 MB of RAM while the background daemon stays active.

To reopen the GUI:
- Click or right-click the **OSMV Tray Icon** in your notification area and choose **Show Configuration** (**Afficher la configuration**).
- Or launch `OSMV.exe` (Windows) / `./osmv` (Linux) again: it detects the running daemon over IPC and opens the GUI window.

---

## Why is my System Tray Icon invisible on Linux?

OSMV implements `org.kde.StatusNotifierItem` and `com.canonical.dbusmenu` directly over `libdbus-1` (no GTK dependency required).

- **Hyprland / Sway / Waybar**: Ensure the `"tray"` module is enabled in your Waybar configuration.
- **GNOME**: Install and enable the [AppIndicator and KStatusNotifierItem Support](https://extensions.gnome.org/extension/615/appindicator-support/) extension.
- **Fallback**: You can always open the interface manually by running `./osmv --gui` or `./osmv-gui`.

## Can I make OSMV launch automatically on startup?

Yes. Open **Settings** in OSMV and toggle **Start OSMV with system (in background)**:
- **Windows**: Registers `OSMV.exe --silent` under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\OSMV`.
- **Linux**: Writes `~/.config/autostart/osmv.desktop` executing `./osmv --silent`.

Using `--silent` starts only the lightweight background daemon without opening the GUI window until you request it.

## How do I assign OSMV to a workspace in Sway / Hyprland / i3?

`osmv-gui` explicitly sets desktop window identifiers at startup:
- **Wayland (`xdg_shell`, GLFW 3.4+)**: `app_id="io.github.streammusicviewer.OSMV"`
- **X11 / XWayland (`WM_CLASS`)**: `instance="osmv"`, `class="OSMV"`

Example for `~/.config/sway/config`:
```sway
assign [app_id="io.github.streammusicviewer.OSMV"] workspace number 9
```

Make sure you build against **GLFW 3.4+** on Wayland (`glfw` on Arch, `glfw-devel` on Fedora, or `libwayland-dev libwayland-bin libxkbcommon-dev` on Ubuntu 24.04 so CMake builds GLFW 3.4 automatically).

## Can I change where `.txt` files are generated?

Yes. In **Settings -> Dynamic text files directory**, enter any custom path (or click **Reset Default** to revert to `shared/dynamic_text/`). All **Copy** buttons across the interface update automatically to match your chosen directory.

---

## Can I use different OBS overlay styles across different scenes?

Yes. In **Now Playing -> Presets & Style**, configure your overlay, enter a preset name under **Saved Presets (Multi-Scene OBS)**, and click **Save Preset**. Use **Scene URL** (or append `?preset=<Name>` to `shared/index.html`) and add it to OBS as a Browser Source with **Local file** unchecked. Each scene loads its matching preset from `shared/widget_config.js` while reading live tracks from `shared/current_song.js`.
